Using a token

Send it as a bearer token. These two endpoints accept one; everything else needs a sign-in.

curl -H "Authorization: Bearer YOUR_TOKEN" \
  {{ origin }}/api/{{ exampleCourse() }}/statuses

curl -H "Authorization: Bearer YOUR_TOKEN" \
  {{ origin }}/api/{{ exampleCourse() }}/grades

Add /csv to the grades URL for the same export the submissions page offers.
